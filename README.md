An alien tourist's one-star review of planet Earth — with a sincere
compliment about the food slipped in. The program writes a single
sentence (at most 200 characters) to `/output/entry.txt`.

> One star: Earth charged me rent for gravity, the traffic sang in
> gridlock, yet the street tacos made my third stomach weep with joy.

## Run

```sh
node main.ts
```

It validates the sentence (one sentence, 1–200 characters, no newline)
and writes it to `/output/entry.txt`.
